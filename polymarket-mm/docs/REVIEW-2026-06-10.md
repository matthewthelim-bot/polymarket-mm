## Open items — not yet fixed

### Needs verification before live (high priority)

1. **`src/strategy/hedgeability.py:131` — sell-side hedge threshold.**
   For `quote_side=SELL`, `max_flatten_price` (a BUY ceiling) is reused as a
   bid-price floor. The profitable sell-hedge condition is
   `p_flatten >= 1 - p_fill + fees + edge`, a different bound — bids in the
   gap are counted as hedgeable when selling there locks in a loss. Needs a
   dedicated `min_flatten_price_for_sell` derivation in `FeeModel` plus tests.
2. **`src/live/exit_checker.py:98` — counts our own resting orders as exit
   liquidity.** A market where the only "exit depth" is our own bid passes
   the viability check. Needs own-order stripping like the live book filters.
3. **`src/live/quote_loop.py` — unroutable fills (`unknown_*`) are immortal.**
   They can never be matched by `_retry_open_positions`, accumulate against
   `max_open_positions`, and permanently halt the market's quoting. Needs an
   expiry/alert path.
4. **`src/backtest/runner.py:143` — `BacktestRunner` never wires `portfolio`.**
   Single-market backtests run uncapped (live_harness does wire it). Either
   pass it through or document that runner-path results ignore caps.

### Architecture / performance (medium)

5. **`src/live/quote_loop.py:256` — blocking REST `get_book` inside the async
   WS callback.** Up to 10s stall blocks every market on the feed; should be
   replaced by subscribing the NO token on the WS (the handler exists).
6. **Four `_check_*_fill` quadrants in `simulator.py`** are still ~70-line
   near-clones (the recorders were unified this pass; the checkers were
   patched in place). One parameterized checker would prevent future drift.
7. **`QuoteLoop._compute_quote` duplicates `BacktestSimulator._compute_quote`**
   — backtest/live parity depends on hand-synced copies. Extract to shared.
8. **Three copies of the CLOB market-metadata fetch** (`run_live.py`,
   `run_live_backtest.py`, `run_sensitivity.py`) — same API workaround,
   three maintenance points.
9. **`book_feed._handle_price_change`** rebuilds and re-sorts the whole book
   per delta message — O(L log L) where O(log L) would do.
10. **`run_live.py` `seen_fill_ids` grows unbounded** over long sessions
    (bounded only by account trade count; low risk, easy cap).

### Test gaps (medium)

11. **Zero tests for the live path** (`quote_loop.py`, `book_feed.py`,
    `clob_client.py`, `exit_checker.py`) — the highest-stakes code. The
    hedge-routing table and `_send_taker` partial-fill handling are the
    most valuable targets.
12. **Quote engine untested at extremes** — fv near 0.01/0.99, HEDGE_PENDING
    3x multiplier, crossed-quote guard.
